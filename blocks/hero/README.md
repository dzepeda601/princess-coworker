# hero

Custom **hero** block. Purpose: Full-width page-opening banner with a background image and an overlaid text panel (optional eyebrow tagline, H1 heading, body copy, CTA).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = one image (optionally a second row with a second image for the dark theme); last row = text cell with an optional tagline paragraph, an H1 heading, optional body paragraph(s) and an optional CTA link.

## Supported variations

| Variation | Option class |
| --- | --- |
| Rust background | `rust` |
| Gold background | `gold` |
| Ink background | `ink` |
