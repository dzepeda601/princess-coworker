# cards

Custom **cards** block. Purpose: Responsive grid of content cards, each with an optional image and a body of heading, text and link.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: image cell (picture) + body cell (heading, paragraphs, optional link); a single cell holding image and text also works.

## Supported variations

| Variation | Option class |
| --- | --- |
| Links (from query index) | `links` |
| Bento grid | `bento` |
